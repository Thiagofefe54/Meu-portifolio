**Tecnologias:** HTML · CSS · JavaScript · GSAP

## Sobre

Portfólio pessoal com apresentação, projetos selecionados, tecnologias e formulário de contato. A ideia é acompanhar minha evolução e reunir os trabalhos em um só lugar.

## O que já existe

- Cards de projetos com links para código ou demonstração.
- Animações, efeito de texto e menu móvel.
- Formulário conectado ao Formspree.

## Como visualizar

Clone o repositório e abra `index.html` no navegador. Para testar por HTTP, use a extensão Live Server do seu editor. Preserve as pastas de CSS, JavaScript e imagens. Não há dependências locais para instalar; recursos de CDN exigem internet.

## Observações

O formulário depende de um serviço externo. As demonstrações vinculadas podem estar em desenvolvimento.
